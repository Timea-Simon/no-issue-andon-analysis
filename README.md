# No Issue Andon Analysis

## Project Overview
This project analyzes operational andon cases to identify patterns in no issue and valid issue reports across shifts, associates, and andon categories.

The analysis was created using Excel and Power BI.

---

## Tools Used
- Excel
  - Data cleaning
  - Pivot Tables
  - Data preparation
- Power BI
  - Dashboard creation
  - KPI reporting
  - Data visualization
  - Basic DAX measures

---

## Key Findings
- Morning and Night shifts showed more incorrect cases than Mid shift.
- Damaged Item and Incorrect Title were the most common incorrect andon categories.
- Some inconsistencies may reflect differences in individual issue evaluation.
- Several associates showed recurring incorrect reporting patterns.

---

## Recommendations
- Review evaluation criteria for Damaged Item and Incorrect Title cases.
- Improve consistency in issue evaluation standards.
- Continue monitoring recurring no issue andon patterns.
